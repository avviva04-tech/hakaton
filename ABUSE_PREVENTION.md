# Запобігання зловживанням

| Ризик зловживання | Запобіжник у MVP | Наступний етап |
|---|---|---|
| Формальне закриття без реального ефекту | Окремі показники заходу й ризику, сигнали недосягнення цілі | Незалежна перевірка якості вимірювань |
| Виконавець сам погоджує свою роботу | Серверна заборона погодження для ролі виконавця | Додаткове розділення повноважень серед координаторів |
| Приховане переписування документа | Незмінні файли, версії, SHA-256, аудит | Підпис і довготривале незалежне сховище |
| Видалення незручного заходу | Архівування замість видалення, аудит | Контроль архівування другою особою |
| Часте перенесення строків | Лічильник і сигнал після двох змін | Погодження зміни строків за регламентом |
| Перегляд чужих документів | Перевірка належності на сервері | Повноцінна багатоустановна модель доступу |
| Приховування сигналу | Позначка «взято до уваги» не усуває активну причину | Контроль часу опрацювання |
| Використання системи для звинувачень | Немає рейтингів персоналу й висновків про винуватість | Політика етичного використання та оскарження |
| Підроблені вимірювання | Автор, дата, пояснення й історія кожної оцінки | Докази вимірювань та незалежний контроль |

Рекомендації є підставою для перевірки, не доказом порушення. Користувач має перевірити якість вихідних даних. Локальна база й деморежим не придатні для реальних кадрових рішень.
