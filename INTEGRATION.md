# Карта майбутньої інтеграції

Прямого підключення до систем НАЗК чи Міністерства оборони України **немає**. Жодні дані не надсилаються до цих систем. Поточний спосіб — перевірений людиною експорт PDF/XLSX/CSV і ручне перенесення.

## Поточне зіставлення

| Поле системи | Поле звітної структури                                    |
| ------------ | --------------------------------------------------------- |
| Розділ I     | Загальна відомча політика, стратегія та державна програма |
| Розділ II    | Усунення корупційних ризиків                              |
| Розділ III   | Навчання та поширення інформації                          |
| `actualDate` | Фактичний строк виконання                                 |
| `status`     | Стан виконання                                            |
| `result`     | Результат або причини невиконання                         |
| `continuous` | Фактична дата 30 червня / 31 грудня                       |

## Умови реалізації адаптера

1. Отримати офіційну специфікацію API, правові підстави й тестове середовище відповідної установи.
2. Узгодити довідники, ідентифікатори, класифікацію даних та формат підпису. Поточний експорт не є гарантією відповідності невідомій API-схемі.
3. Створити серверний адаптер, окремий від UI і внутрішніх моделей. Секрети зберігати тільки на сервері.
4. Додати попередню валідацію, показ пакета користувачу та явне підтвердження відправлення.
5. Реалізувати ідемпотентність, повторні спроби, квитанції, журнал передачі й звірку станів без дублювання записів.
6. Провести тестування, аналіз загроз і незалежний аудит. Лише після цього заявляти про діючу інтеграцію.

До отримання специфікацій можливість позначається як майбутня. Вигаданих URL чи імітації успішного відправлення немає.
