# Безпека та контроль доступу

## Реалізований захист

- Сервер слухає лише loopback `127.0.0.1`.
- Паролі хешуються bcrypt із вартістю 12 через bcryptjs; хеші не повертаються клієнту.
- Токен сесії: 32 криптографічно випадкові байти; у БД зберігається його SHA-256. Строк — 8 годин.
- Cookie: HttpOnly, SameSite=Strict; Secure вмикається `COOKIE_SECURE=true` для HTTPS.
- Мутації з чужим `Origin` відхиляються. Вхід обмежений 50 спробами за 15 хвилин з IP.
- Сервер перевіряє роль і належність заходу виконавцю. Вгадування ID не дає доступу до чужого заходу або документа.
- Zod перевіряє поля; Prisma параметризує SQL. Єдине raw-SQL звернення — константний `SELECT 1` для health check.
- Файли не публікуються статично: скачування потребує сесії й дозволу. Кожна версія має випадковий фізичний шлях, не перезаписує оригінал і перевіряється за SHA-256 під час завантаження.
- Ліміт файлу 10 МБ, один файл на запит; тип визначається за байтами й має відповідати розширенню.
- React екранує введений текст; CSV нейтралізує префікси формул.
- Немає маршрутів зміни/видалення аудиту. Паролі й відкриті токени не записуються в аудит.
- Секрети та БД виключено з Git. Зовнішніх API й передачі даних третім сторонам немає.

## Межі довіри

Демонстраційний режим навмисно дозволяє вхід без пароля до визначених синтетичних облікових записів. Для звичайного середовища вимкнути `DEMO_MODE`, змінити демопаролі, організувати HTTPS та окрему перевірку безпеки. Це не заявка на готовність працювати з реальною службовою інформацією.

Перевірка сигнатур не є антивірусом чи повною перевіркою активного вмісту PDF/Office. Файли слід завантажувати лише синтетичні; антивірус, карантин і захист від архівних бомб — вимоги наступного етапу. SHA-256 не підтверджує правдивість документа.

Локальний адміністратор ОС може змінити БД або файли. Для захисту від такого противника потрібні окремі права ОС, резервні копії, підписані журнали в незалежному сховищі та контроль доступу до резервів.

Скидання демоданих доступне лише адміністратору в деморежимі й потребує слова `СКИНУТИ`; журнал зберігається. Фізичні попередні файли автоматично не видаляються.

## Залежності

За результатом `npm audit` після налаштування overrides — 0 відомих вразливостей. Зафіксовано сумісні виправлені транзитивні `deepmerge-ts`, `effect`, `uuid`; для оновлення повторити збірку, генерацію Prisma та тести. Стан advisories змінюється з часом.
