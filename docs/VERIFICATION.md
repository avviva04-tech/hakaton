## Що покривають регресійні перевірки

- CLUSTER лише для заходів із власними сигналами, незалежно від порядку.
- Строк сьогодні не прострочений; учора прострочений; 00:30 за Києвом і перехід літнього часу.
- Матриця переходів усіх п’яти ролей; заборона ручних OVERDUE/NOT_DUE, самопогодження та погодження без документа.
- Повторне збереження виконавцем у REVIEW заборонено; координатор отримує повідомлення.
- Матриця доступу до користувачів, аудиту, налаштувань, звітів, сигналів, рекомендацій, створення й оновлення заходів.
- Публічний демосписок не містить email; Host стороннього домену відхиляється.
- Результат, документи, дві версії PNG, SHA-256, фальшивий PDF, експорт JSON/CSV/XLSX/PDF і аудит.
- GET аналітики не змінює записи сигналів.
- Реактивація проблем скидає статус і строк рекомендації; зміна строкового повідомлення скидає прочитання.
- NO_RISK_CHANGE очікує вимірювання після виконання та враховує останній показник перед початком.
- Запит перерахунку під час поточного проходу очікує наступного проходу.

Вимірювання швидкодії — локальний контрольний запуск, а не гарантія для будь-якого обладнання. Перерахунок усіх сигналів після запису залишається повним; великі набори потребуватимуть інкрементального аналізу. Панель показує до 12 ризиків із 12 останніми вимірюваннями; загальні лічильники враховують усі записи. Календар має фільтри from/to, але його інтерфейс поки завантажує всі короткі записи програми.

Збірка попереджає про пакет графіків понад 500 КБ і анотації оптимізації Zod. Помилок збірки немає. Тести не вимикалися. Тимчасові каталоги залишаються у .tools поза Git для діагностики.

## Межі виконаного рев’ю

Виконано програмні пункти фаз 0–3 промпта ментора та чернетку фази 4: форматування, дати, стани, права, пароль, структура, продуктивність, повторна активація, вимірювання ризику, повідомлення, розділення роутерів, читабельність інтерфейсу та ізоляція тестів.

Загальне архітектурне зауваження Q2 виходить за ці конкретні кроки: ролі/статуси зберігаються як рядки з перевіркою в застосунку; автори документів/коментарів — знімки імен, підрозділи — довідник у коді; налаштування БД використовує db push, а не версійовані міграції. Ці властивості не позначаються як виправлені. Світла тема не додавалася; шрифт збільшено, контраст вторинного тексту покращено, повний аудит WCAG не проводився.

## Українська локалізація форм

Стандартні повідомлення HTML-форм замінено власними українськими повідомленнями, а файлові поля — кнопкою «Обрати файл» та написом «Файл не вибрано». Деморежим показує лише вибір ролей. API-тести використовують /auth/demo, без паролів. Системне вікно вибору файлів належить ОС; його мову вебзастосунок не змінює.

## Рішення керівника

Перевірено цикл виконавець → координатор → керівник → звіт. API перевіряє відмову з поясненням, повторну подачу, схвалення, заборону рішення координатором, повторного рішення та зміни результату керівником. Документи блокуються під час розгляду та після завершення. Відмова і схвалення з автором, датою та обґрунтуванням зберігаються в аудиті й експортуються у PDF/XLSX/CSV. Архівування не приховує рішення за звітний період.
