# Використання штучного інтелекту

Команда: **VUI IT**.

## Інструменти й для чого

Codex допомагав перевіряти зауваження ментора, форматувати та виправляти TypeScript/React/Express-код, писати регресійні тести й оновлювати документацію. Ця декларація описує підтверджене використання інструменту в роботі над репозиторієм.

У застосунку немає зовнішніх ШІ API, LLM чи передачі документів стороннім сервісам. Сигнали формують детерміновані правила з відкритими умовами; рішення ухвалює людина.

## Вимоги команди

Команда визначила українську мову інтерфейсу, демонстраційний вхід без паролів та послідовність роботи: виконавець подає результат, координатор перевіряє матеріали, керівник схвалює або повертає на доопрацювання з поясненням. Рішення керівника включається у звіт для вищого керівництва.

## Реалізовані технічні рішення

Система окремо показує виконання заходу, досягнення його цілі та зміну ризику. Використано п’ять ролей, локальну SQLite, синтетичні демонстраційні дані та правила аналізу замість LLM. Прямої інтеграції з НАЗК немає.

## Як перевіряли згенерований код

TypeScript, production-збірка, тести календарних меж, переходів і CLUSTER, наскрізний API-сценарій із матрицею прав, тимчасова БД, перевірка демоскидання, браузерні перевірки та вимірювання на 1000 заходах.
